# 주간 보고서 — v81a → v144a (2026-05-26 → 2026-06-11)

GroundedDNA 프로젝트의 약 2주간 진행 보고서. v81a (직전 SOTA, mAP 0.6879) 이후 발생한
구조적 변경과 손실함수 변경의 핵심만 정리했다. 10분 분량 보고용.

**공통 세팅**: 36-bit DNA hash (6 codebooks × 3 codons × 2 base, L=3), batch size 64,
60 epoch, 비지도 (`--hash_target_mode siglip_cos`).

---

## 1. 한 줄 요약

지난 2주 동안 (1) **백본을 SigLIP2 → CLIP-ViT-B/16로 교체** 하면서 unsupervised mAP가
0.69 → 0.77 대로 점프했고, (2) **supervision regime을 진정한 unsupervised로 정정** 한 뒤
recipe를 재구축했으며, (3) **codeword↔codon Sinkhorn bijection** 과 **codon 길이 L=3 → L=4**
같은 구조적 변경으로 compositional 축(DNA-uniq, NMI)을 본격적으로 끌어올렸다.
v144a는 K=128에서 **mAP 0.7499 / P@1 0.917 / NMI 0.591 / DNA-uniq 0.376** 으로
현재의 K=128 compositional Pareto-better 후보다.

## 2. 주요 구조적 변경 사항

### 2-1. CLIP 백본 교체 (5/27, v88a-CLIP)
- 단일 변경: SigLIP2-base/patch16 → **OpenAI CLIP-ViT-B/16** (다른 hyperparameter 동일).
- Flickr25k mAP **0.6879 → 0.7853 (+0.097)**, P@1 0.79 → **0.9025**.
- CLIP의 image-text contrastive pretraining이 compositional VQ hashing 신호와 더 부합.
- 이후 모든 후속 실험의 기본 백본으로 채택.

### 2-2. Supervision regime 정정 (6/2)
- 그간 "unsupervised SOTA" 로 보고된 v81a~v95a 계열은 사실 `--hash_target_mode jaccard`
  로 학습되어 **Flickr25k의 38-tag multi-hot label을 pairwise similarity로 사용** 하고 있었다.
- 진정한 비지도를 위해 `--hash_target_mode siglip_cos` (frozen CLIP visual_global self-similarity)
  를 **hard invariant**로 지정.
- regime 정정 직후 v101c (mAP 0.7729, DNA-uniq 0.231) 가 진정한-비지도 기준 첫 mAP champion.

### 2-3. Codeword↔Codon Sinkhorn Bijection (v106b)
- 6개 codebook 각각의 K개 codeword를 `4^L`개 codon에 **OT permutation**으로 정렬시키는
  새로운 손실 도입 (`loss_codeword_codon_sinkhorn`, λ=0.1).
- "K codeword를 K개 distinct 3-base codon에 강제 정렬" 하여 codeword→DNA codon collision
  문제를 직접 제어. v106b가 paper-final reference로 자리.

### 2-4. Codon 길이 L=3 → L=4 (v122a, 6/9)
- 단일 구조 변경. codon 알파벳 4^L = 64 → **256**, 한 codebook 당 DNA 비트 6→8,
  전체 DNA 비트 36→48.
- K=256일 때 perfect bijection (1:1 permutation) 가능, K-scaling 천장이 사라짐.
- **DNA-uniq 0.347 → 0.551 (+59%)**, P@1 0.917 → 0.9215 (family record).
- v122a는 cross-dataset paper-final candidate (단, MSCOCO port는 v118a처럼 −0.053 mAP 실패 후
  recipe 추가 조정 진행 중).

### 2-5. Local-residual quant γ=1.0 OFF (v132a, 6/9)
- v122부터 도입된 `--local_residual_quant γ=1.0` (C0 projection 제거) 가 사실
  **NMI/B1/B2에 0 기여, 오히려 mAP와 P@1을 깎고 있었다는 점이 인과적으로 입증**.
- v132a (= v128a − local-residual): 모든 retrieval 축에서 v128a를 **strict Pareto-dominate**
  (mAP +0.005, P@1 +0.010, NMI 0.636 동률).
- 디폴트 recipe에서 제거.

### 2-6. K=128 채택 + Partial whitening γ=0.25
- K=64 → K=128 (v118 계열). 같은 codon (4^3=64) 에 codeword 2개씩 배치되어
  "redundant route to same codon" 이 DNA-uniq의 *enabler* 역할.
- Partial whitening γ=0.25는 codebook usage 균등화 + dead codeword 방지를 위한 표준 옵션.

### 2-7. Text supervision 입자도: per_codebook (v128a 이후)
- 텍스트 NtXent를 (전체 DNA 위가 아니라) **codebook 단위로 분해** 한 형태가 compositional axis
  (NMI 0.59–0.62의 sweet spot)의 load-bearing driver. global cibhash (v137a) 는 폐기.

### 2-8. v144a — Codebook-level text-KL distillation (6/11, NEW)
- v144a = v133a + 신규 손실 `loss_text_code_kl` (λ=0.02).
- 시각/텍스트 토큰 각각을 codebook의 codeword에 대한 categorical 분포로 만든 뒤,
  **텍스트→시각으로 KL distillation** (`KL(p_t.detach() ‖ p_v)`).
- 핵심 디자인: **(i) pre-VQ 신호** (VQ bottleneck 우회), **(ii) confidence weighting**
  (텍스트 entropy 높은 noisy caption은 자동 downweight, threshold 0.2), **(iii) cb0(global)
  제외** — cb0은 paired-aug NtXent + DNA regularizer로 이미 supervised.
- 결과: v133a 대비 NMI 0.626 → **0.591** (compositional ↑), DNA-uniq 0.340 → **0.376** (+10%),
  retrieval 거의 tie (mAP −0.004, P@1 +0.002). K=128 compositional Pareto-better 후보 갱신.

## 3. 손실함수 변경 요약

| 손실 | 변경 | 시점 | 영향 |
|---|---|---|---|
| `loss_anchor` | **비활성화** (EMA 코드북 모드에서 gradient = 0 으로 dead-weight 확인) | 6/2 (v98a) | 기존 SOTA 수치는 그대로 유효 (offset만 더해졌음) |
| `loss_hash` (jaccard pairwise) | **λ=0 (제거)** — tag supervision 신호였음 | 6/2 (v101c) | regime 정정 |
| `loss_text_hash_ntxent` | **추가** (text-derived ↔ image-derived 72-dim DNA InfoNCE) | 6/2 (v101c) | mAP +0.05, DNA-uniq ×7.5 |
| `loss_codeword_codon_sinkhorn` (bij) | **추가** — codeword↔codon Sinkhorn OT | v106b | DNA-uniq 회복 기제 (paper claim) |
| `loss_text_cluster_codon_ot` (thNX) | 추가 (보조) | v106b 부근 | dead-codeword 방지 |
| `loss_cibhash_per_codebook` | global → **per_codebook + dynamic τ** | v128a | NMI 0.59–0.62 sweet spot |
| `loss_local_residual_quant` (γ=1.0) | **제거** (no-op-or-harmful 인과 입증) | 6/9 (v132a) | mAP +0.005, P@1 +0.010 |
| `loss_text_code_kl` (KL distillation + confidence) | **추가** (cb0 제외) | 6/11 (v144a) | NMI −0.035, DNA-uniq +0.036, retrieval tie |
| `loss_base_balance` | MSE → **KL(uniform ‖ p̄)** | 6/2 (v102a) | dead codeword 0.27 → 0.01, B1/B2 v9x max |
| `loss_cw_xmodal` (post-VQ contrastive) | **discarded** (v143a 재현 실패) | 6/11 | 폐기 |
| `loss_swav_assign` (SwAV balanced) | **discarded** (VQ ↔ SwAV mutual exclusivity) | 6/9 (v121a) | 폐기 |

**해석 (다축 비교)**:
- **mAP / deep-rank**: ours가 모든 외부 baseline을 추월 (v144a +0.066 over CIMON, +0.066 over CIBHash).
- **P@1 (top-1 sharp)**: CIBHash 0.9365가 여전히 1위. v122a 0.9215와 격차 −0.015로 좁힘.
- **DNA-uniq**: 외부 flat baseline은 hash 자체가 instance-unique를 직접 supervise하므로
  여전히 0.5~0.97 우위. ours는 v122a의 **L=4 (48-bit) 확장**으로 0.551까지 회복했으며,
  36-bit 범위에서는 v144a의 0.376이 우리 family 최고.
- **NMI / B1 (compositional)**: ours가 압도적 우위. v144a NMI 0.591은 "낮을수록 compositional",
  external baseline은 0.16~0.32로 사실상 *그룹 자체가 무작위 partition*에 가까움 (즉
  compositional 구조 자체가 없음). B1 lift도 ours가 1.5–2.0× 우위.

**해석**:
- **mscoco_v144a 가 새 recipe 라인의 MSCOCO mAP/P@1/P@10 champion**: mscoco_v133a 대비 mAP
  +0.004 / P@1 +0.014 / P@10 (직접 비교는 v133a 부재이나 0.808 vs v132a 0.804) 동시 개선.
  Flickr25k v144a (mAP −0.004 retrieval tie) 와 달리 **MSCOCO에서는 retrieval 까지 함께

- 단 CIBHash-CLIP (mAP 0.5842) 와는 여전히 −0.015 mAP gap, P@1 은 −0.114 격차. 80-class
  fine-grained multi-label retrieval 에서 flat hash 의 top-rank sharpness 우위는 유지.
- mscoco_v91a-CLIP K=128 (mAP 0.6374) 이 수치상 우리 family 최고이지만 jaccard regime 잔류
  영향 가능성이 남아 있어 직접 비교는 보류. siglip_cos regime 라인의 진정한 비지도 champion
  은 **mscoco_v144a (mAP 0.5693)**.
- mscoco_v133a 의 NMI 0.687 은 여전히 compositional 축 최고이며, **bij ON/OFF의 인과 방향이
  Flickr 와 MSCOCO 에서 반대** 라는 흥미로운 발견: MSCOCO 는 텍스트 coverage 가 낮아서
  bij 가 dead codeword 를 예방하는 부담을 짊어져야 한다.

### 4-3. 구조적 두 regime의 분리 (paper-worthy)

| 차원 | Flat regime (CIBHash) | Compositional regime (v144a/v122a) |
|---|---|---|
| Top-1 / Top-10 sharpness | **excellent** | very good |
| mAP / deep rank coverage | weak | **best** |
| NMI | 0.16 (사실상 random partition) | 0.59–0.64 (sweet spot) |
| Drop ablation 분포 | 모든 cb 균일 기여 | cb0 dominant + 차등 기여 |
| DNA-uniq (36-bit) | 0.97 (instance-unique) | 0.34–0.38 |
| 효과적 비트 수 | 36개 모두 informative | 12–24개로 더 적은 비트로 동등 mAP |
| Compositional 해석 | 불가능 (구조 없음) | codebook = visual primitive |

이 dichotomy는 hyperparameter 차이가 아니라 **hashing approach의 구조적 속성**임이 동일 백본 위에서 입증됨.

## 6. 향후 방향성

1. **v144a 의 MSCOCO port 결과 확인 완료** — mscoco_v144a (mAP 0.5693 / P@1 0.812 /
   NMI 0.660) 가 mscoco_v133a 를 모든 retrieval 축에서 추월. cross-dataset 으로 text_code_kl
   의 효과 확인. 다음 단계는 CIBHash-CLIP MSCOCO (mAP 0.5842) 와의 −0.015 gap 좁히기.
2. **v144a λ sweep** (0.01, 0.05) 및 cb0 inclusion ablation — 현재 0.02 + skip_global이 sweet
   spot인지 확인.
3. **v122a + noLocalRes (= v135a)** 로 L=4 K=256 paper-final 의 mAP/DNA 동시 회복 시도.
4. **CIBHash 와의 P@1 gap 해소** — Flickr25k 에서 −0.015 까지 좁혀졌으나 여전히 외부 baseline 우위.
   v144a + per_codebook 프로토타입 stacking 후속.
