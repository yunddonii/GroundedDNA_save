# v160b_qwen3 vs v144a — Flickr25k / MSCOCO 변경 사항 및 비교

GroundedDNA — v144a (2026-06-11 baseline) → v160b (2026-06-16) 사이의 구조 변경 정리.
모든 결과는 frozen CLIP-ViT-B/16 backbone, K=128 codebook, L=3 codon (36-bit DNA hash),
batch size 64, 60 epoch, Qwen3-VL v4 caption cache 의 동일 세팅에서 측정되었다.

---

## 1. v160b 의 구조적 정의

v160b 는 v144a 의 단일 베이스가 아니라 **v150b 의 입력 측 재구성** + **v160a 의
cross-modal commitment loss** 를 *합성한* recipe 다.

```
v144a (baseline, 2026-06-11)
   │
   │  ── Pre-VQ 측면 재구성 (v147a/v150b 라인)
   │     1) cibhash NtXent 위치 이동: post-VQ bit_probs → pre-VQ D-dim semantic_visual_tokens
   │     2) Sinkhorn 라우터 → UOT (Unbalanced OT, λ=1.0)
   │     3) top-p 인터벌 0.5/0.9 → 0.3/0.7 (sharper)
   │  ── 결과: v150b
   │
   │  ── 손실 측면 추가 (v160a 라인, Uni-Code Eq.(8))
   │     4) λ_xmodal_commit = 0.025 신규 추가
   │
   ▼
v160b = v150b recipe + `--lambda_xmodal_commit 0.025`
```

### 1-1. 구조적 변경 4건 (v144a → v160b)

| # | 변경 | 위치 | 효과 |
|---|---|---|---|
| 1 | **CIBHash NtXent 입력 변경** | post-VQ `bit_probs` (6-bit slice) → **pre-VQ `semantic_visual_tokens` (D-dim, M=6 슬롯)** | NtXent gradient 가 7-level quantized cosine 천장을 우회해 인코더에 직접 도달; **dead codeword 0.065 → 0.000** + B1/B2 (text-anchored compositional lift) family-best 갱신 |
| 2 | **Router: Sinkhorn → UOT** | balanced OT → Unbalanced OT (λ=1.0) | 1번이 도입한 attractor crystallization 을 mass redistribution 으로 상쇄. v150a (1번만 적용) 는 DNA collapse → 1번 + 2번이 **synergistic** |
| 3 | **top-p 인터벌 sharpening** | 0.5/0.9 → **0.3/0.7** | 라우팅 sparsity 강화. UOT 와 결합해 codebook 활용률 100% 유지 |
| 4 | **Uni-Code Eq.(8): cross-modal commitment loss 신규** | encoder 출력 (z_v, z_t) ↔ 반대 모달 quantized (q_t, q_v) 의 L2 commit | `L_xmodal = 0.5 × (‖z_v − sg[q_t]‖² + ‖z_t − sg[q_v]‖²)` (λ=0.025). 표준 self-modality commitment 는 그대로 유지하고 **cross-modal 항을 *추가*** |

### 1-2. 손실함수 추가 / 변경 요약

| 손실 | v144a | v160b | 비고 |
|---|---|---|---|
| `loss_cibhash_per_codebook` | post-VQ bit_probs (per_codebook + dyn τ) | **pre-VQ visual_token (per_codebook + dyn τ)** | source 변경, M=6 NtXents on [B, D] |
| `loss_text_code_kl` | λ=0.02 (skip_global), confidence weighting | **그대로 유지** | v144a 의 핵심 loss 그대로 |
| `loss_text_hash_ntxent` | 활성 | 활성 | 변경 없음 |
| `loss_codeword_codon_sinkhorn` (bij) | OFF (v133a 라인) | OFF | 변경 없음 |
| **Router** | Sinkhorn balanced + topp 0.5/0.9 | **UOT λ=1.0 + topp 0.3/0.7** | 구조 변경 |
| `loss_xmodal_commit` (Uni-Code Eq.(8)) | — (없음) | **λ=0.025 신규 추가** | encoder cross-modal commitment |

## 2. v160b 결과 — Flickr25k vs MSCOCO

### 2-1. Flickr25k v160b vs v144a

| Metric | v144a | **v160b** | Δ | 해석 |
|---|---:|---:|---:|---|
| mAP | 0.7499 | 0.7390 | **−0.011** | 약간 손실 (수용 가능) |
| P@1 | 0.9170 | 0.9170 | tied | retrieval top-1 동률 |
| DNA-uniq | 0.376 | **0.400** ★ | +0.024 (+6.4%) | family record (첫 baseline 추월) |
| cb_tuple uniq | 0.664 | 0.536 | −0.128 | 라우팅 categorical화로 감소 |
| collision ratio (cbT/DNA) | 1.77× | **1.34×** ★ | −0.43 | family record, L=3 limit 최근접 |
| NMI mean ↓ | 0.591 | 0.630 | +0.039 | redundancy 약간 ↑ |
| L↔L NMI ↓ | 0.657 | 0.671 | +0.014 | small regression |
| **B1 lift (text)** | 0.125 | **0.162** ★ | +0.037 (+30%) | family record |
| **B2 lift (visual)** | 0.076 | **0.100** ★ | +0.024 (+32%) | v150a 와 family max tied |
| dead codeword | 0.065 | **0.000** ★ | −0.065 | full [128]×6 활용 |

**Flickr25k 메시지**: mAP/NMI 를 약간 양보 하고 **interpretability (B1/B2)** 와
**collision (DNA-uniq + ratio)** 두 축을 family 최고치로 끌어올린 trade-off.

### 2-2. MSCOCO mscoco_v160b vs mscoco_v144a

| Metric | mscoco_v144a | **mscoco_v160b** | Δ | 해석 |
|---|---:|---:|---:|---|
| mAP | 0.5693 | **0.6134** ★ | **+0.044 (+7.7%)** | MSCOCO retrieval 대폭 개선 |
| P@1 | 0.8120 | **0.8970** ★ | **+0.085 (+10.5%)** | family record |
| P@10 | 0.8078 | **0.8902** ★ | +0.082 | 깊은 rank 도 함께 ↑ |
| DNA-uniq | 0.126 | 0.119 | −0.007 | 거의 tied |
| cb_tuple uniq | 0.291 | 0.205 | −0.086 | 약간 ↓ |
| NMI mean ↓ | 0.660 | 0.726 | +0.066 | 약간 redundancy ↑ |
| L↔L NMI ↓ | 0.707 | 0.755 | +0.048 | 약간 ↑ |
| **B2 lift (visual)** | 0.138 | **0.166** ★ | +0.028 (+20%) | MSCOCO family record |
| dead codeword | 0.085 | **0.000** ★ | −0.085 | first MSCOCO cell with 100% utilization |

**MSCOCO 메시지**: Flickr 에서의 trade-off 방향이 **반대로 뒤집힘** — mAP/P@1/B2/dead 가
모두 동시에 개선되는 **Pareto improvement**. mscoco_v160b 가 MSCOCO 의 mAP + P@1 + B2 +
utilization 4축 동시 champion 으로 자리잡음.

### 2-3. Trade-off 방향 반전의 메커니즘 (paper-grade 결론)

| | Flickr (caption coverage 100%) | MSCOCO (caption coverage 8.2%) |
|---|---|---|
| Eq.(8) cross-modal commit 발화 빈도 | 매 batch | ~8% batch |
| v160a (Eq.8 alone) vs v144a | mAP +0.012, DNA −0.058 | mAP +0.005, DNA −0.036 |
| v160b (v150b + Eq.8) vs v144a | mAP **−0.011**, B1/B2/DNA ↑ | mAP **+0.044**, P@1 +0.085, B2 +0.028 |

MSCOCO 는 caption 이 희소해 Eq.(8) 이 *rate-limited* 가 되며, 대신 v150b 의
visual_token NtXent + UOT 가 매 batch 발화 → **두 loss 가 gradient bandwidth 를 두고 경쟁하지
않게 됨**. 결과적으로 Flickr 의 "compositional vs retrieval trade-off" 가 MSCOCO 에서는
Pareto improvement 로 완화된다.

## 3. Unsupervised Baseline 대비 비교

모두 동일 CLIP-ViT-B/16 backbone + 36-bit code + 60 epoch + bs=64. 외부 baseline 은
별도 head (e.g., CIBHash 는 `Linear(512, 36)` + paired-aug NtXent).

**Flickr25k 해석**:
- **mAP**: v160b 0.7390 은 외부 baseline 모두 추월 (+0.005 over CIBHash, +0.007 over CIMON).
- **P@1**: CIBHash 0.9365 가 여전히 1위. v160b 0.917 와 격차 −0.020. v122a (L=4) 가 0.9215 로
  격차 −0.015 까지 좁힘.
- **Unique code**: 외부 flat baseline 은 hash 자체가 instance-unique 를 직접 supervise 하므로
  여전히 0.5~0.97 우위. v160b 는 36-bit (L=3) 범위에서 우리 family 신기록 (0.400) 갱신.
  48-bit (v122a, L=4) 까지 확장하면 0.551.
- **Compositional (B1/B2/NMI)**: **v160b 의 B1 0.162 / B2 0.100 은 우리 family 신기록 동시에
  외부 baseline 의 2-3× 우위**. 외부 baseline 은 NMI 0.16~0.32 로 사실상 그룹 자체가 무작위
  partition (compositional 구조 없음).

## 4. 종합 — v160b 의 페이퍼 포지셔닝

| 우선순위 축 | Flickr 챔피언 | MSCOCO 챔피언 | 참고 |
|---|---|---|---|
| #1 Interpretability (B1/B2) | **v160b** (B1 0.162, B2 0.100) | **mscoco_v160b** (B2 0.166) | family record 동시 갱신 |
| #2 Text-supervision (low NMI) | v147b (NMI 0.508) | mscoco_v148b (NMI 0.580) | v160b 는 NMI 약간 손실 |
| #3 Retrieval (mAP) | v160a (0.7617) | **mscoco_v160b (0.6134)** | MSCOCO 는 v160b 가 champion |
| #3 Retrieval (P@1) | v122a (0.9215) | **mscoco_v160b (0.897)** | MSCOCO 는 v160b 가 champion |
| #4 Collision (K=128, L=3) | **v160b** (DNA 0.400, 1.34×) | mscoco_v160h (DNA 0.155, K=256) | Flickr K=128 family 신기록 |

**한 줄 요약**: v160b 는 **Flickr 에서는 interpretability + collision 두 축의 family
champion** 으로 (mAP 약간 양보), **MSCOCO 에서는 retrieval + interpretability + utilization
4축 동시 champion** 으로 (Pareto improvement) — 동일 recipe 가 두 데이터셋에서 다른 우선순위
축에 fit 되는 cross-dataset 발견이 핵심.

## 5. 향후 방향성

1. **v160b + L=4 (v122a 스타일 codon space 확장)** — Flickr/MSCOCO 모두에서. 예상:
   DNA-uniq 0.55+ + B1 0.16+ + retrieval mAP > baseline. 페이퍼 finale 후보.
2. **λ_xmodal_commit sweep** {0.01, 0.025, 0.05, 0.1} on mscoco_v160b — 8.2% caption coverage
   에서의 sweet spot 재확인.
3. **mscoco_v160h K=256 의 결과**가 이미 multi-axis champion 으로 확인됨 — 이를 Flickr 로
   port 하는 v160h Flickr 실험이 차순위.
